# V-entry Lottery

X（旧Twitter）の投稿に「いいね」したユーザーから、当選3名＋補欠2名を抽選する Google Apps Script です。
スプレッドシートのメニューから、取り込み・除外・抽選まで完結します。

## 機能

- X API から「いいね」したユーザーを取得し、シートに一覧化
- 応募条件を満たさない人をチェックボックスで除外
- SHA-256 による、あとから検証できる抽選
- 一度確定した結果は再抽選できない（引き直し防止）
- 取り込み後の名簿差し替えも、抽選確定後はブロック

## シートの構成

初期設定を実行すると、次のレイアウトが作られます。

| 列 | 内容 |
|----|------|
| A | 応募者X ID（`@username`） |
| B | 除外チェックボックス |
| C | Xプロフィールへのリンク |
| D | 表示名 |
| E | 区分（当選1〜補欠2） |
| F | 抽選結果のX ID |
| G | 当選者の表示名（F列を基にD列をVLOOKUP） |
| H | 項目名 |
| I | 投稿URL / 取込日時 / 取得人数 / 抽選日時 / 抽選シード |
| J | YouTube URL、無ければ本人がプロフィールに設定しているURL（参考） |

A〜D列が応募者名簿、E〜G列が抽選結果、H〜I列が実行ログ、J列が参考情報です。

## セットアップ

### 1. X API の認証情報を用意する

[X Developer Portal](https://developer.x.com/) でアプリを作成し、次の4つを取得します。

- API Key
- API Secret
- Access Token
- Access Token Secret

アプリ側で **ユーザー認証（OAuth 1.0a）を有効化** し、**Read 権限**を付与してください。
なお `liking_users` エンドポイントは無料プランでは使えません。Basic 以上の契約が必要です。

### 2. スクリプトプロパティに登録する

Apps Script エディタの `プロジェクトの設定` → `スクリプト プロパティ` に、次のキーで登録します。

| キー | 値 |
|------|-----|
| `X_API_KEY` | API Key |
| `X_API_SECRET` | API Secret |
| `X_ACCESS_TOKEN` | Access Token |
| `X_ACCESS_TOKEN_SECRET` | Access Token Secret |

> 認証情報をコードに直接書かないでください。
> スクリプトプロパティに入れておけば、このリポジトリをそのまま公開しても鍵は漏れません。

### 3. スクリプトを配置する

1. 新しいスプレッドシートを作成する
2. `拡張機能` → `Apps Script` を開く
3. `Code.gs` の中身を貼り付けて保存する
4. スプレッドシートを再読み込みする
5. メニューバーに `V-entry抽選` が現れる

## 使い方

1. **① シートを初期設定** — 列見出しとチェックボックス、G列の数式を作ります
2. **I1セルに募集投稿のURLを貼る** — `https://x.com/xxx/status/1234567890` の形式
3. **② Xから応募者を取り込む** — いいねしたユーザーがA〜D列とJ列に入ります
4. **B列で除外にチェック** — 応募条件を満たさない人を外します
5. **③ 当選3名＋補欠2名を抽選** — E〜G列に結果が確定します

## 抽選の仕組み

1. UUID を2つ連結してシードを作る
2. 応募者ごとに `SHA-256(シード | ユーザーID)` を計算する
3. そのハッシュ値の昇順に並べ、上位5名を 当選1〜3・補欠1〜2 とする

シードは I5 セルに記録されます。名簿とシードが揃っていれば同じ結果を再現できるため、
第三者があとから抽選の正当性を検証できます。

抽選結果が入っている状態では、再抽選も名簿の取り込み直しもできません。
引き直しを防ぐための意図的な仕様です。

## 制限と注意

- 取得できるのは最大 2,000 名です（`MAX_API_PAGES` × 100件）。超えた分は打ち切られ、その旨が通知されます
- 有効な応募者が5名未満だと抽選できません
- 鍵アカウント・削除済みアカウントのいいねは取得できません
- J列は参考情報です。空欄でも抽選対象からは外れません
- 「① シートを初期設定」は E1:F6 を空で上書きします。**抽選確定後は実行しないでください**
- X API のレート制限に達した場合は、しばらく待ってから再実行してください
